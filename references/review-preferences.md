# 维护者的复习资料偏好

确认日期：2026-10-20。本文是维护者可选择继承的历史偏好预设，不是自动施加给每次任务的默认规范。启动时按 [可定制配置](customization.md) 获取本次需求；明确选择沿用时再采用本预设，当前要求始终优先。本文不包含课程原始文件、个人作答或机器路径，也不授权发布其他资料。

## 1. 阅读顺序与覆盖范围

- 以 PPT/讲义的实际介绍顺序为主线，保留章节及页段对应关系。每章先讲解，再放对应练习；允许在需要的位置插入数学基础补充。
- 讲解要连贯、有详略，不按孤立考点切成大量碎片。考点清单用于检查遗漏，不替代阅读结构。
- 对所有已提供 PPT、作业与考试范例检查覆盖。难点、推导和范例相关内容详讲，历史背景、工具概览等按讲义要求简讲。
- 考试范例是重要的深度和题型依据：完整读取原题、图和公式，逐项核对其假设、要求、分值与作答语言。范例未注明的规则不要编造。
- “覆盖所有可能考点”应落实为“覆盖已提供材料中的重要内容和适用条件”，不能保证预测未来考题，更不能默默推测未提供的后续讲义。

## 2. 英文表述与中文解释

考试采用英文时，学习资料使用完整英文表述，后面紧接对应的中文解释。中文要解释这句话在当前问题中意味着什么，不能只有孤立单词的翻译，也不能全文仅用中文。

**术语规则以最后确认的形式为准：正文首次出现时写英文全称，后面紧接中文解释；后续不重复加注。**

- 缩写示例：`Principal Component Analysis (PCA)（主成分分析：寻找保留最大数据方差的正交方向）`。
- 非缩写也要解释，例如 `orthogonal projection（正交投影：沿垂直方向把点映射到指定直线或子空间）`。
- T、E、P 应写明 `Task（任务）`、`Experience（经验）`、`Performance measure（性能衡量指标）`，不能只给三个中文词。
- 不在每节开头堆术语表，不设置反复出现的“术语先读”“范例术语回顾”，也不让附录词表代替首次使用处的解释。
- 默认按整份资料实际阅读顺序判断首次出现，涵盖章节正文、例题与答案；不要每章重置并重复展开。标题、导航和目录不塞入长定义。
- 单独导出的模拟卷或节选属于独立文档，按其用途决定是否重新介绍必要术语。闭卷模拟版通常保持英文原题，学习版可按用户要求随文加注。
- 相同字母在不同情境中含义改变时必须重新定义，例如 P 可表示性能指标，也可能是 precision；这不是重复解释同一术语。
- 没有通用英文展开式的模型、工具或实现模块名，保留准确名称并解释作用，不编造全称。

实现时保护数学表达式、代码、文件名、URL 与引用。不要用无差别字符串替换：`scatter matrix` 与 `KL divergence` 虽都可能译含“散度”，不是同一个概念；`positive definite` 与 `positive semidefinite` 不能混淆。检查英文单复数、语序和括号，避免插入说明后句子读不通。

## 3. 新手能跟上的数学讲解

读者不应被默认已掌握微积分、矩阵运算或机器学习记号。每条关键公式应说明：

1. 它解决什么问题，输入与输出是什么。
2. 所有符号的意义：标量/向量/矩阵、维度、下标范围、转置、导数、求和与运算符。
3. 从哪一个定义或上一行出发，用了哪条规则，怎样逐步得到下一行。
4. 结论表达什么，何时成立，常见错误是什么。
5. 适合时用一个小算例检验，并检查尺寸、符号、概率范围或极端情况。

特别注意：

- 横杠记号应明确为本资料的约定，如 $\bar z_i=\partial L/\partial z_i$，表示最终损失对该变量的导数，不是均值或更新值。
- $\odot$ 是逐元素乘法，与矩阵乘法不同；$B^Tg$ 为什么需要转置、结果的尺寸是什么，都要交代。
- 推导反传时，先画清或描述计算路径，再说明“一条路径局部导数相乘，多条路径贡献相加”。
- 对 $h=\sigma(z),y=Bh+x$，解释先得到隐藏状态梯度 $B^Tg$，再逐位置乘 $\sigma'(z)$；若激活在加法之后，先乘输出激活导数再分配到两条路径。
- Sigmoid 导数是维护者标记过的重要推导。说明从倒数与指数求导到
  $\sigma'(z)=e^{-z}/(1+e^{-z})^2$，再利用
  $e^{-z}=(1+e^{-z})-1$ 得到 $\sigma(z)[1-\sigma(z)]$，不能只给最终恒等式。
- PCA/最小二乘证明应解释投影系数、正交距离、二次型、特征向量基、等号条件及重特征值时的不唯一性；不要省略关键代数变形。

用户批注“重要”表示其个人复习优先级，不等于教师确认必考。应在相关内容中保留或体现该重点，不改变课程考试范围的事实陈述。

## 4. 少而有区别的题目

- 新任务启动时询问题量及“精确数量/数量上限”，不默认 60 道。60 道可作为问答示例；已有约定题数时保持该数量。DASE7140 的 55 道是具体交付约定，不是技能通用常量。
- 每题记录独立的训练目的，例如 `unique_focus`。题目若只换数字、变量名、表面场景或句式，应合并或删除。
- 题目覆盖计算、纠错、证明、适用条件、边界情形、反例和应用决策，不用大量浅层选择题取代困难综合题。
- 对考试范例优先提供完整推导与答案，再补真正不同的训练。抽取已有题组成模拟卷时，不把同一道题重复计入总题量。
- 答案说明理由与适用条件；自评分项标为非官方，不能冒充原卷评分标准。
- 练习优先保持考试语言；中英讲解及释义方式以用户对学习版/模拟版的要求为准。

## 5. 网页阅读与导航

- 保留侧边章节导航，可展开小节目录、点击跳转；让读者知道当前章节。
- 同时可跳到讲解和对应练习，支持从题目回看相关讲解，优先“先看讲解，再做题”的阅读路径。
- 手机窄屏时导航可收起，不能遮挡正文；长公式和表格不得被裁掉。
- 保持离线可用，字体、公式库和必要图片可内嵌。跨设备交付文件或压缩包，不把本机盘符或 localhost 当作公网分享地址。
- 简答/证明题记录已练习或已查看解析，不能把“查看答案比例”冒充掌握程度或正确率。
- 纯文案与排版更新尽量保留现有题号、收藏和作答；题意或答案改变时按变更范围处理存储兼容性，不假装旧评分仍有效。

## 6. 微信阅读与 PDF 同步

- 维护者需要在其他设备、尤其微信中阅读。HTML 若打开卡顿，提供完整静态 PDF；不要让用户继续依赖重型网页脚本。
- 网页和 PDF 从同一内容源生成，同步正文、术语、公式、题目与答案。不要把修订只放到一个格式里。
- PDF 展开全部内容，包括网页折叠的解析、图和推导；不能导出只有目录、标题或题目而漏掉隐藏答案的版本。
- 使用适合手机阅读的字号与页宽，保留可点击目录、章节书签和页码；在可读前提下控制文件体积，不把正文全部栅格化成图片。
- 网页可折叠内容并预渲染公式以减轻首屏负担，但不能为减小文件而删掉推导或答案。
- 文件正被打开而无法覆盖时，另存清晰的新版本并交付该文件，避免误指向旧版。

## 7. 准确性与验收

维护者对准确性要求很高，曾提出 95% 以上的目标。把它落实为可核验的检查，不凭主观估计宣称“已达 95%”，也不保证考试得分。

- 优先核对课程原材料，必要时补充教材、原论文或官方文档；记录支持相应结论的来源，区分课程要求与补充知识。
- 所有数值答案独立验算；重点推导检查假设、维度、链式依赖、求和/平均因子和等号条件。
- 比较生成前后的讲解数、唯一题目数、答案数及公式内容；禁止因排版或术语改写丢失数学内容。
- 检查首次术语是否就地展开、后续是否重复加注、是否有残留的节首术语清单。
- HTML 在实际浏览器中检查公式错误、目录跳转及相关交互；不把脚本源码中的 `katex-error` 字符串算作渲染错误。
- PDF 全文提取核对内容完整性，并渲染代表页面检查长公式、中文字体、分页、答案和范例推导。必要时排除页脚及文本提取顺序导致的假缺失。
- 交付时给出实际文件及已做检查，不用“生成成功”替代完整性验证。

课程 project 是另一个交付物：单独读取任务书、接口和评分要求，不能把复习题答案当作项目实现；项目材料和个人数据不随本偏好文档上传。
