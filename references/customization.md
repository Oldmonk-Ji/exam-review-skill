# 启动问答与可定制配置

本技能由本次配置驱动；历史例子和维护者偏好都不是硬编码的课程模板。

## 启动时怎么问

先提取当前请求、已有对话和项目配置中已经明确的值，只问缺失项。材料读取、范围盘点可以同时推进；不把问答做成阻塞全部工作的审批流程。

首次使用可合并成三组简短问题，允许自由填写：

1. **题量与目标**：“这次希望多少道题，是精确数量还是最多多少道？也可以提供剩余复习时间，让我建议。只整理讲解、不出题也可以。”可以给 20 / 40 / 60 道作示例，但不可预选 60 或把它当作上限。若用户让助手建议，先根据覆盖范围和时间提出具体数量，等待确认再批量出题。
2. **阅读方式**：“希望按讲义顺序、主题还是考试题型整理？讲解用中文、英文还是英文紧接中文？数学推导需要基础补充、标准步骤还是简要结论？”已明确的子项不要再问。可选择“沿用已知偏好”，但不要替用户选择。
3. **交付方式**：“需要网页、PDF、Markdown，还是多种格式？主要在电脑、手机/微信还是纸上阅读？”多格式只生成被选择的格式。

后续按任务需要再问题型比例、闭卷时长、答案位置等；不一次抛出十几道必答题。可选细节无人回答时采用已说明的暂定方案；题量、必须遵守的范围等关键项未确定时保持待定。没有答复不等于确认。

**继续旧任务**：已有题量和输出要求就沿用，除非用户要求更改；不要因为重新调用技能就重复启动问卷。用户改一项，只更新受影响的配置与产物。

## 配置维度

| 配置 | 可选方式 | 影响 |
|---|---|---|
| 材料与范围 | 全部已提供材料、指定章节、明确排除项 | 内容覆盖与来源检查 |
| 学习目标 | 从零理解、系统复习、考前冲刺、模拟考试 | 讲解与练习的比例 |
| 时间预算 | 自由填写，或未知 | 建议题量与深度，不能自动替用户确认 |
| 阅读顺序 | 讲义顺序、主题、考试题型、自定义 | 章节和小节结构 |
| 学习路径 | 先讲后练、练习后回看、独立讲义与卷子 | 讲解及练习的位置 |
| 语言 | 中文、英文、双语或其他指定语言 | 正文、题目、解析可分别配置 |
| 双语布局 | 英文后紧接中文、并排、中文主体保留英文术语 | 段落呈现方式 |
| 术语方式 | 首次随文解释、每章首次解释、词表、按用户定义 | 去重范围及释义位置 |
| 数学基础 | 新手补基础、标准、进阶精简 | 符号解释和推导粒度 |
| 推导深度 | 逐步推导、关键步骤、公式与条件摘要 | 讲解长度；精简不能写出错误等式 |
| 题量 | 精确 N、最多 N、只讲解、助手提案待确认 | 计数规则；无固定 60 题默认值 |
| 题型 | 计算、证明、纠错、概念、选择/判断、综合应用 | 题型比例与交互 |
| 难度 | 基础、混合、接近范例、挑战，或指定比例 | 推理复杂度 |
| 范例侧重 | 完整覆盖、优先深化、自定义 | 复习重点；不据此承诺命中考试 |
| 变式方式 | 独立推理目标；明确要求时可少量计算重复训练 | 重复训练单独计数、标注，不能假装独立题 |
| 答案位置 | 紧随题目、章末、卷末、单独答案册 | PDF 排版与网页展开方式 |
| 网页 | 静态/互动；侧栏/顶部目录；搜索、收藏、计时、进度 | 只实现选择的功能 |
| 图示 | 必要图示、丰富图示、不配图 | 配图工作量与输出体积 |
| 输出与设备 | Markdown、HTML、PDF；电脑、手机/微信、打印 | 页宽、字体、资源内嵌和分页 |
| 外部资料 | 仅提供材料、允许权威资料补充 | 来源范围；缺证据处如实说明 |
| 视觉与进度 | 主题、字号、页尺寸；保留/迁移作答 | 样式与数据兼容 |

配置取值冲突时优先执行当前明确要求，其次是当前项目已确认配置，再其次是明确选用的历史预设。检测到冲突应指出具体冲突并解决，不悄悄覆盖。

## 保存与实施

复制 [配置模板](../assets/review-config.example.yaml) 到输出项目的 `review-config.yaml`。这是**供执行技能的助手读取的任务契约**，不是声称现有构建脚本已经能直接消费的命令行参数文件。暂不支持的选项需要适配构建器或采用其他合适工具；不能只保存配置而让产物忽略它。

- 为关键决定标明来源：当前请求、已有对话、用户选择、助手暂定建议。
- `null` 表示待定，不表示零、不出题或同意默认值。
- 准确记录精确题数和题量上限的区别。“只讲解”显式选择 `none`。
- 保存简短配置摘要；不要求用户对已经明确的内容再次批准。
- 同一内容源生成所选格式。多格式更新同步；只有用户要求 PDF 时才执行 PDF 工序。
- 用户的考试日期、个人作答、私有路径等项目配置留在项目内，不随技能仓库自动发布。

## 可定制不等于放弃质量检查

所有配置都保留：不伪造来源和考试范围、数学结论与条件一致、数值答案验算、题目与答案完整、声明实际验证边界。输出语言、题量、重复训练与版面按本次配置验收，而不是使用历史固定数量或“题目区零中文”之类不适用的断言。

例如：

- 用户选择“最多 20 道、英文闭卷模拟卷、答案卷末、只要 PDF”，则不生成 60 题或互动网页，题干保持英文。
- 用户选择“80 道计算熟练训练、允许有标明的重复练习”，则不以 60 为上限拒绝，但要把重复训练与独立推理题区分计数。
- 用户选择“不出题、中文基础讲义、Markdown”，则跳过题库、判题、PDF 和 HTML 工序。
- 用户要求沿用上一份资料但改为“术语首次随文解释”，只调整释义方式及相关导出，保持已确认题量。
